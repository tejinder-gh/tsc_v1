# T-008 — Remediate Next.js and Sharp security vulnerabilities

**Source finding:** AUDIT_REPORT.md CTO-01 | Severity: P0 | Class: BROKEN  
**Assigned tier:** SENIOR  
**Effort estimate:** 1.5h | **Sequence:** independent

## WHAT
Update project dependencies to eliminate critical and high-severity CVEs identified in `npm audit`. Specifically, upgrade `next` from `16.3.0` to the latest stable release (>= `16.3.3` or within the `^16.1.0` / current major version) that resolves `GHSA-2xp9-vwfh-vxw4` (Unauthenticated Remote Code Execution in Image Optimization API via AVIF) and `GHSA-p293-qw3h-jr36` (Unauthenticated RCE on Windows servers). Also ensure `sharp` is updated to >= `0.35.4` to remediate memory corruption vulnerabilities in `libheif` (`GHSA-rgj7-g3m4-5g8c` / `GHSA-2jg2-4ch7-h545`).

## WHY
Next.js's built-in image optimization endpoint (`/_next/image`) is publicly accessible and processes user-supplied images. The AVIF processing bug in unpatched Next.js 16 allows unauthenticated attackers to execute arbitrary code on the server, posing a catastrophic risk to production infrastructure and hosted data.
